# Примечания

- **[Алгоритм GhostRider (Raptoreum)](https://github.com/xmrig/xmrig/blob/master/src/crypto/ghostrider/README.md)**
- [Бенчмарк RandomX](https://xmrig.com/benchmark)
- [Примечания к выпуску KawPow](https://github.com/xmrig/xmrig/pull/1694#issuecomment-638310915)
- Следите за обновлениями, следите за мной на X - https://x.com/xmrig_dev.
- [Мастер конфигурации](https://xmrig.com/wizard)
- [Панель управления для майнеров](http://workers.xmrig.info/)
- Для майнинга на NVIDIA CUDA, используйте любую версию с [плагином CUDA](https://github.com/xmrig/xmrig-cuda).

# v6.27.0

- [#3805](https://github.com/xmrig/xmrig/pull/3805) ARM64 JIT: оптимизировано преобразование регистров группы E
- [#3807](https://github.com/xmrig/xmrig/pull/3807) Обновлена структура шаблона блока для FCMP++
- [#3808](https://github.com/xmrig/xmrig/pull/3808) Исправлена сборка с OpenSSL 4.0
- [#3812](https://github.com/xmrig/xmrig/pull/3812) RandomX: инициализация набора данных (dataset) на RISC-V ускорена на 2,5%
- [#3815](https://github.com/xmrig/xmrig/pull/3815) ARM64: оптимизации JIT RandomX
- [#3816](https://github.com/xmrig/xmrig/pull/3816) ARM64: оптимизации RandomX
- [#3820](https://github.com/xmrig/xmrig/pull/3820) ARM64 RandomX JIT: предвыборка (prefetch) набора данных и невременные загрузки (non-temporal loads) (~8% быстрее на Apple M4)
- [#3826](https://github.com/xmrig/xmrig/pull/3826) Исправлена инструкция ISUB_R в JIT-компиляторах для ARM и RISC-V
- [#3835](https://github.com/xmrig/xmrig/pull/3835) Добавлено определение процессоров ARMv9 и оптимизированные флаги сборки
- [#3837](https://github.com/xmrig/xmrig/pull/3837) Исправлены вызовы madvise: их значения не являются битовыми масками, поэтому теперь передаются по одному
- [#3841](https://github.com/xmrig/xmrig/pull/3841) RISC-V: в AES-ядрах RVV исключены индексные загрузки и сохранения
- [#3844](https://github.com/xmrig/xmrig/pull/3844) Исправлен RandomX v2 при сборке ассемблером Apple (в нём `;` означает комментарий)
- [#3845](https://github.com/xmrig/xmrig/pull/3845) ARM64: сокращена инвалидация кэша JIT
- [#3848](https://github.com/xmrig/xmrig/pull/3848) Обновлён код соло-майнинга FCMP++ для beta stressnet v3
- [#3857](https://github.com/xmrig/xmrig/pull/3857) DaemonClient: добавлена проверка отпечатка TLS, использование SOCKS5 (если он настроен), исправлена утечка сокета при неудачном подключении к ZMQ
- Сборки MSVC теперь используют hwloc из xmrig-deps вместо встроенной копии, требуется новая версия xmrig-deps
- Исправлена сборка с OpenSSL 3 и новее, собранными без устаревшего (deprecated) API
- Исправлена сборка с libuv 1.53.0 на Windows
- Исправлена сборка с Clang на Windows ARM64 (MSYS2)
- Обновлены скрипты сборки зависимостей: libuv 1.53.0, hwloc 2.15.0 и OpenSSL 3.5.9 без неиспользуемых функций
- macOS: добавлена поддержка новой версии xmrig-deps; указание только CMAKE_OSX_ARCHITECTURES=x86_64 теперь позволяет собрать x64-версию на Apple Silicon.

## _Обзор_

Это новая версия программного обеспечения Monero GUI 0.18.5.1. Данная версия содержит большое количество исправлений ошибок.

Краткий обзор последней версии CLI можно найти в [предыдущем посте](https://www.getmonero.org/2026/07/08/monero-GUI-0.18.5.1-released.html).

Некоторые особенности новой версии:

- Исправлена проблема с безопасностью памяти при сканировании QR-кодов ([#4597](https://github.com/monero-project/monero-gui/pull/4597))
- Исправлено редкое зависание кошелька при завершении работы ([#4603](https://github.com/monero-project/monero-gui/pull/4603))
- Предотвращено внедрение формул при экспорте CSV ([#4609](https://github.com/monero-project/monero-gui/pull/4609))
- Обеспечено единообразное экранирование текста во всех элементах форматированного текста ([#4610](https://github.com/monero-project/monero-gui/pull/4610))
- Исправлен спам в консольном журнале при запуске приложения ([#4615](https://github.com/monero-project/monero-gui/pull/4615))
- Добавлена проверка доступности каталога при создании файла кошелька ([#4617](https://github.com/monero-project/monero-gui/pull/4617))
- Добавлен диалог подтверждения для неподтверждённых записей OpenAlias ([#4618](https://github.com/monero-project/monero-gui/pull/4618))
- Исправлено стандарное имя в файле рабочего стола ([#4590](https://github.com/monero-project/monero-gui/pull/4590))
- Скрыто всплывающее окно обновления при запросе парольной фразы устройства ([#4623](https://github.com/monero-project/monero-gui/pull/4623))
- Добавлен идентификатор записи для рабочего стола приложения ([#4625](https://github.com/monero-project/monero-gui/pull/4625))
- Обновлён P2Pool до версии 4.17.1 ([#4620](https://github.com/monero-project/monero-gui/pull/4620))
- Незначительные исправления ошибок и улучшения

Полный список изменений [выложен на GitHub](https://github.com/monero-project/monero-gui/compare/v0.18.5.0...v0.18.5.1) вместе с [исходным кодом](https://github.com/monero-project/monero-gui/tree/v0.18.5.1).


Подписанный GPG список хешей можно найти по этой ссылке: https://getmonero.org/downloads/hashes.txt. Он является каноническим, а подписи сверяются с соответствующим ключом GPG в исходном коде (в /utils/gpg_keys). Чтобы проверить наверняка, были ли скачанные вами файлы изначально загружены мейнтейнерами, следует проверить как соответствие хешей ваших файлов тем, что указаны в списке, так и соответствие подписи под списком.

В процессе верификации вам помогут эти два руководства: [Verify binaries on Windows (beginner)](https://www.getmonero.org/resources/user-guides/verification-windows-beginner.html) (Проверка двоичных файлов в Windows (для начинающих)) и [Verify binaries on Linux, Mac, or Windows command line (advanced)](https://www.getmonero.org/resources/user-guides/verification-allos-advanced.html) (Проверка двоичных файлов посредством командной строки Linux, Mac или Windows (продвинутый уровень)).

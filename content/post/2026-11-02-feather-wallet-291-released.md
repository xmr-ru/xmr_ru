## _Уведомление_

Встроенный демон Tor, поставлявшийся с предыдущим релизом Feather, устарел. Пользователям, которые не могут подключиться к узлу, рекомендуется обновиться до этой версии, установить Tor на уровне системы или открыть Tor Browser и изменить порт Tor-прокси в Feather на 9150. Либо отключить Tor в Feather.

## _Исправления_

- Мастер настройки: ручное изменение параметра упреждающего просмотра подадресов (subaddress lookahead) теперь работает при восстановлении из мнемонической фразы из 25 слов.
- Различные мелкие исправления ошибок.

## _Устаревшие функции_

- История: удалён столбец «Фиат».
  - Мне так и не удалось наладить надёжное получение исторических данных о ценах. Возможно, я верну эту функцию позже.
- Удалены плагины «Майнинг» и «Вознаграждения» (Bounties).
  - Сервис на основе WebSocket постепенно выводится из эксплуатации. Зависящие от него функции будут постепенно удаляться. Конвертация фиатных и криптовалютных цен в реальном времени по-прежнему будет поддерживаться.
- Прекращена поддержка Linux на ARM32.
  - Это может коснуться вас, если вы запускаете Feather на Raspberry Pi с 32-битной ОС. Большинство моделей Raspberry Pi способны работать с 64-битной ОС, поэтому рассмотрите возможность перехода на неё.
- Релиз для Windows больше не имеет цифровой подписи кода.
  - Я занялся подписанием кода, ошибочно полагая, что улучшение репутации в SmartScreen поможет уменьшить количество ложных срабатываний антивирусов. Это не помогло — скорее, ситуация с антивирусами стала только хуже. Подписание кода слишком усложняет процесс воспроизводимой сборки.
  - Отказ от подписи кода не влияет на безопасность релизов: подпись кода никогда не заменяла проверку GPG-подписей с помощью ключа подписи релизов.
  - Я перестал искать обходные пути, чтобы угодить антивирусам, и не хочу больше тратить на это время.
- Минимальная поддерживаемая версия macOS теперь 14 (ранее была 12).

## _Обслуживание_

- Monero обновлён до версии v0.18.5.1
- Qt обновлён до версии v6.11.1
- Tor обновлён до версии 0.4.9.11
- Релизы для Linux и Windows теперь собираются с GCC 15.2 (ранее 12.4)
- Релизы для macOS теперь собираются с Clang 22 (ранее 18)

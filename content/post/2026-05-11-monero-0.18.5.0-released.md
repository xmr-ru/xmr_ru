## _Обзор_

Это новая версия программного обеспечения Monero 0.18.5.0. Данная версия добавляет поддержку SOCKS v5, удаляет поддержку UPnP и содержит большое количество исправлений некритических ошибок.

Некоторые особенности новой версии:

- Добавлена поддержка SOCKS v5 для демона и кошелька ([#10411](https://github.com/monero-project/monero/pull/10411))
- Демон: удалена поддержка UPnP ([#10465](https://github.com/monero-project/monero/pull/10465))
- Демон: исправлена проблема с зависанием кошелька при завершении работы ([#10494](https://github.com/monero-project/monero/pull/10494), [#10401](https://github.com/monero-project/monero/pull/10401), [#10489](https://github.com/monero-project/monero/pull/10489))
- Демон: улучшена обработка исключений ([#10437](https://github.com/monero-project/monero/pull/10437), [#10373](https://github.com/monero-project/monero/pull/10373))
- Демон: ускорен метод `get_complement()` пула транзакций для больших запросов ([#10377](https://github.com/monero-project/monero/pull/10377))
- Демон: добавлены ограничения для RPC-метода `add_aux_pow` ([#10409](https://github.com/monero-project/monero/pull/10409))
- ZMQ: добавлен ограниченный режим RPC ([#10389](https://github.com/monero-project/monero/pull/10389), [#10420](https://github.com/monero-project/monero/pull/10420), [#10425](https://github.com/monero-project/monero/pull/10425), [#10469](https://github.com/monero-project/monero/pull/10469), [#10504](https://github.com/monero-project/monero/pull/10504))
- ZMQ: исправлено отображение транзакций в пуле на стадии "стебля" ([#10399](https://github.com/monero-project/monero/pull/10399))
- ZMQ: добавлено уведомление о событии txpool при переходе из стадии "стебля" в стадию "пуха" ([#10453](https://github.com/monero-project/monero/pull/10453))
- Кошелёк: улучшена проверка доказательств ([#10480](https://github.com/monero-project/monero/pull/10480), [#10471](https://github.com/monero-project/monero/pull/10471), [#10481](https://github.com/monero-project/monero/pull/10481), [#10473](https://github.com/monero-project/monero/pull/10473))
- Кошелёк: добавлена опция пропуска обновления после импорта мультиподписи ([#10402](https://github.com/monero-project/monero/pull/10402))
- Кошелёк: добавлена проверка корректности адреса сдачи ([#10431](https://github.com/monero-project/monero/pull/10431))
- Кошелёк RPC: добавлена информация об источнике в `describe_transfer` ([#10380](https://github.com/monero-project/monero/pull/10380))
- Кошелёк RPC: исправлен разбор разрешённых SSL-отпечатков в `set_daemon` ([#10433](https://github.com/monero-project/monero/pull/10433))
- Кошелёк RPC: ограничены чувствительные методы в режиме `--restricted-rpc` ([#10379](https://github.com/monero-project/monero/pull/10379), [#10435](https://github.com/monero-project/monero/pull/10435))
- Усилена обработка аутентификации HTTP-клиента ([#10364](https://github.com/monero-project/monero/pull/10364))
- Добавлена поддержка автоматической сборки для архитектуры LoongArch ([#10400](https://github.com/monero-project/monero/pull/10400))
- Различные исправления ошибок и улучшения

Полный список изменений [выложен на GitHub](https://github.com/monero-project/monero-gui/compare/v0.18.4.6...v0.18.5.0) вместе с [исходным кодом](https://github.com/monero-project/monero-gui/tree/v0.18.5.0).

Он является каноническим, а подписи сверяются с соответствующим ключом GPG в исходном коде (в /utils/gpg_keys). Чтобы проверить наверняка, были ли скачанные вами файлы изначально загружены мейнтейнерами, следует проверить как соответствие хешей ваших файлов тем, что указаны в списке, так и соответствие подписи под списком.

В процессе верификации вам помогут эти два руководства: [Verify binaries on Windows (beginner)](https://www.getmonero.org/resources/user-guides/verification-windows-beginner.html) (Проверка двоичных файлов в Windows (для начинающих)) и [Verify binaries on Linux, Mac, or Windows command line (advanced)](https://www.getmonero.org/resources/user-guides/verification-allos-advanced.html) (Проверка двоичных файлов посредством командной строки Linux, Mac или Windows (продвинутый уровень)).

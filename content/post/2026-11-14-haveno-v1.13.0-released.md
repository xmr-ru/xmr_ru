## _Исправления безопасности_

- Обновление Tor до версии v0.4.9.15 (Tor Browser 16.0), выпущенной как релиз безопасности.
- Запрос пароля кошелька перед отображением приватных ключей.
- При сохранении вложения из спора предлагается только простое имя файла, чтобы пир не мог повлиять на место его сохранения.
- Предотвращено сокрытие настоящих сообщений почтового ящика (mailbox) поддельными.
- Ограничена скорость, с которой пиры могут добавлять постоянные данные в сеть.
- Учётные данные для входа на узел Monero больше не передаются в командной строке процесса кошелька.
- Ключи мобильных уведомлений и содержимое сообщений не попадают в журналы.
- Вызовы API, превысившие ограничение частоты запросов, больше не выполняются.
- Требование пароля при создании аккаунта через API, если использование паролей обязательно.
- Пароль для CLI считывается из переменной окружения или запрашивается в диалоге.
- Проверка инструментов сборки, используемых для создания установщиков.

## _Пользовательский интерфейс_

- Предложения о продаже XMR могут требовать от тейкера подписанный платёжный аккаунт.
- Повтор звукового уведомления о непрочитанной активности по сделке, по умолчанию каждый час.
- График глубины рынка стал интерактивным: предложения на графике связаны со списками предложений.
- График глубины рынка центрируется по рыночной цене и растягивается до краёв области графика.
- Щелчок по строке в списке предложений по валютам открывает книгу предложений этой валюты.
- Фильтры книги предложений, поля поиска в таблицах и селекторы рыночной валюты отображаются в виде «плашек» (pills).
- Отображение логотипа выбранной валюты в выпадающих списках валют.
- Фиатные валюты перечисляются по названию и коду, с зелёными значками.
- Список рыночных валют сортируется по количеству предложений по всем типам валют.
- Добавлены итоговые значения по всем сделкам, сделкам с фиатом и сделкам с криптовалютой на график сделок.
- Списки узлов Monero отображаются во вкладках, поэтому просмотр списка не приводит к переключению узла.
- Давние сбои узлов Monero отображаются как непроверенные.
- Параметры предложения поясняются с помощью информационных значков вместо всплывающих окон.
- Отображение зарезервированных средств, если резервируется не точная сумма предложения.
- Отображение сделок, завершённых или отменённых через арбитраж, в истории сделок.
- Отображение отклонения цены в сведениях о сделке.
- Двойной щелчок по транзакции открывает её сведения.
- Обновлены переводы.

## _Исправления ошибок_

- Обновление monero-java до v0.8.65.
- Корректный учёт сделок, урегулированных через арбитраж, в статистике сделок и итоговых значениях истории.
- Исправлена ошибка, из-за которой окно переставало перерисовываться после выхода Windows из спящего режима.
- Исправлено неоткрывающееся восстановление пароля в пакетах для Linux.
- Пояснения при неудачном запуске восстановления пароля и при нечитаемых кошельках.
- Исправлены сбои предложений и сделок, когда единственный арбитр сети медленно подключается.
- Исправлена ошибка, из-за которой неудачное сообщение о подтверждении депозита блокировало отправку сообщения другому пиру до перезапуска.
- Исправлено подписание аккаунта, когда возраст аккаунта пира ни разу не публиковался.
- Сохранение цен и сумм при дублировании предложения.
- Исправлено отображение некоторых отменённых предложений в истории со статусом PENDING.
- Исправлены ошибки при вводе очень больших сумм в полях вывода средств и лимита автоподтверждения.
- Исправлено ожидание неотвечающего узла при редактировании узлов Monero.
- Фильтр по способу оплаты сохраняется, если его выпадающий список закрыт без выбора.
- Введённое в выпадающий список значение применяется при потере фокуса, а поиск в выпадающем списке отменяется клавишей Escape.
- Статус сделки «в споре» связан с кнопкой просмотра спора.
- Цены криптовалют умещаются в селекторе рыночной цены.
- Крупные пакеты сообщений разделяются на части вместо отправки пиру пакетов чрезмерного размера.
- Прекращена отправка уведомлений API отключённым клиентам.
- Использование управляющего порта Tor для определения SOCKS-порта при статическом onion-адресе.
- Обновлены поставщики цен по умолчанию.
- Локальная сеть для разработки запускается в режиме regtest Monero.
- Поддержка Nix shell в NixOS.
- Обновление среды выполнения Flatpak до freedesktop 26.08.

**Полный список изменений**: [v1.12.0...v1.13.0](https://github.com/haveno-dex/haveno/compare/v1.12.0...v1.13.0)

## _Запуск Haveno_

Для достижения наилучших результатов настоятельно рекомендуется запустить _свой собственный локальный узел Monero_, поскольку сеть Tor может работать медленно и ненадежно при синхронизации с удалёнными узлами Monero.

Haveno можно использовать и в основной сети Monero с помощью сторонних сетей. На данный момент мы официально не поддерживаем никакие конкретные сети. Кроме того, вы можете создать собственную сеть, следуя этому [руководству](https://github.com/haveno-dex/haveno/blob/master/docs/create-mainnet.md).

## _Примечания по установке_

Загрузите и установите Haveno с помощью установщика для вашей операционной системы. Установщик предоставляется сетью, которую вы используете. Вы также можете собрать его из исходного кода, адаптировав эту [инструкцию](https://github.com/haveno-dex/haveno/blob/master/docs/installing.md) под выбранную вами сеть.

### _Windows и Linux_

* Перед запуском программы установки удалите все предыдущие версии Haveno.

### _macOS_

1. Откройте программу установки и перетащите Haveno.app в раздел 'Applications'
2. Откройте окно терминала (cmd + пробел, затем введите 'terminal')
3. Скопируйте и вставьте в окно терминала: `sudo xattr -rd com.apple.quarantine /Applications/Haveno.app` и нажмите Enter
4. Введите пароль
5. Щелкните правой кнопкой мыши на /Applications/Haveno.app > Открыть. При необходимости повторите процедуру, даже если выводится сообщение, что приложение повреждено

### _Tails_

* См. [инструкции](https://github.com/haveno-dex/haveno/tree/master/scripts/install_tails). Для обновления повторно выполните однострочную команду установки. Если заменить только .deb-файл в постоянном хранилище (Persistent storage), останется устаревший лаунчер, и Haveno не сможет подключиться к Tor.
* Сетевым администраторам рекомендуется публиковать однострочную команду установки для каждого релиза

### _Директория приложения по умолчанию:_

- Linux: ~/.local/share/Haveno/
- macOS: ~/Library/Application Support/Haveno/
- Windows: ~\AppData\Roaming\Haveno\
